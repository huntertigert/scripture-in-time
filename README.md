# Scripture in Time

An interactive Bible study aid: historical context for all 66 books, a timeline of Bible events beside world history, archaeological finds, and maps. Available in English and Spanish (toggle in the top bar).

It is a single self-contained file, `index.html`. No build step or server code. Open it in a browser, or host it on any static host (GitHub Pages, Netlify, Cloudflare Pages, Vercel).

## Notes
- Dates follow a conventional chronology and are approximate. Map positions are approximate; hollow markers show debated sites. Have a Bible atlas check them before wide use.
- The Spanish text was machine-assisted and should be reviewed by a Spanish speaker.
- Archaeology entries are original summaries that link to articles at the [Biblical Archaeology Society](https://www.biblicalarchaeology.org/).
- Coastlines are derived from [Natural Earth](https://www.naturalearthdata.com/) (public domain) via the `world-atlas` package.
- Fonts load from Google Fonts: Cormorant Garamond, IBM Plex Sans/Mono, Noto Serif.
